# Анализатор строк двумерных массивов

## Описание программы

Программа на C# для анализа двух двумерных массивов символов русского алфавита. Программа проверяет, какие строки массивов содержат только строчные буквы, и выводит соответствующие номера строк.

## Функциональность

- **Анализ двух массивов**: программа обрабатывает два двумерных массива символов
- **Проверка строчных букв**: определяет строки, содержащие только строчные буквы русского алфавита
- **Вывод результатов**: показывает номера строк с строчными буквами для каждого массива
- **Обработка крайних случаев**: выводит сообщение, если подходящих строк нет ни в одном массиве

## Структура программы

### Основные методы:

1. **`ContainsOnlyLowercaseLetters(char[] row)`**
   - Проверяет, содержит ли переданный массив символов только строчные буквы русского алфавита
   - Возвращает `true`, если все символы - строчные русские буквы

2. **`ProcessArray(char[,] array, string arrayName)`**
   - Обрабатывает весь массив, проверяя каждую строку
   - Выводит номера строк, содержащих только строчные буквы
   - Сообщает, если таких строк нет в массиве

3. **`CheckAnyArrayHasLowercaseRows(char[,] array1, char[,] array2)`**
   - Проверяет, есть ли хотя бы в одном массиве строки со строчными буквами
   - Используется для вывода общего сообщения

### Входные данные:

Программа использует предопределенные массивы для демонстрации:

**Массив 1:**
```
а  б  в  г
Д  е  ж  з
и  й  к  л
м  н  о  п
```

**Массив 2:**
```
А  Б  В  Г
Д  Е  Ж  З
р  с  т  у
ф  х  ц  ч
```

## Особенности реализации

- **Ограничение размера**: массивы не превышают 10×10 элементов
- **Русская локализация**: корректно обрабатывает буквы русского алфавита
- **Модульность**: проверка строк вынесена в отдельную процедуру
- **Удобство использования**: понятные сообщения и нумерация строк с 1

## Требования

- .NET Framework или .NET Core
- Поддержка русской кодировки в консоли

## Использование

1. Скомпилируйте программу
2. Запустите исполняемый файл
3. Просмотрите результаты анализа массивов
4. Нажмите любую клавишу для выхода

## Возможные модификации

- Добавление ввода массивов с клавиатуры
- Поддержка других алфавитов
- Изменение критериев проверки символов
- Расширение для работы с массивами большего размера
